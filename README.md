# Карта ML по направлениям

> Ориентир: середина 2026 → стажировка лето 2027. Резюме — до 1 августа.
> Смысл карты не в том, чтобы пройти всё. Смысл — понять ландшафт, выбрать 1 основное направление + 1 запасное и не распыляться.

---

## Слой 0. Фундамент (общий, обязателен независимо от направления)

Это то, что спрашивают на ML-секции собеса почти всегда, вне зависимости от того, куда ты идёшь.

**Математика**
- Линал: матричные разложения (SVD, PCA), нормы, ранг
- Матанализ: градиенты, цепное правило, выпуклость
- Теорвер и матстат: распределения, MLE, байесовская формула, доверительные интервалы, проверка гипотез
- Оптимизация: GD/SGD, momentum, Adam, learning rate schedules

**Классический ML**
- Линейные модели, регуляризация (L1/L2), логрег и её вероятностный смысл
- Метрические методы (kNN), деревья, ансамбли: бэггинг → Random Forest, бустинг → GBDT
- Градиентный бустинг вглубь: CatBoost/LightGBM/XGBoost, различия, обработка категорий, overfitting
- Bias-variance, кросс-валидация, утечки данных, дисбаланс классов
- Метрики: ROC-AUC, PR-AUC, F1, logloss, MAE/RMSE/MAPE — и когда какая ломается

**Deep Learning базовый**
- Backprop руками, инициализация, batch/layer norm, dropout
- PyTorch: датасеты, даталоадеры, тренировочный цикл, mixed precision
- Attention и трансформер — сейчас это фундамент, а не отдельная тема

**Инструменты**
- Python + pandas/numpy/sklearn, Git, SQL (реально спрашивают), bash, Docker

⏱ Если фундамент не закрыт — все остальные ветки бессмысленны. На него разумно потратить основную часть времени до весны 2027.

## Слой 1. Направления

Для каждого: суть → чему учиться по порядку → ключевые модели → что читать → где это в Яндексе.

---

### 1. NLP / LLM https://movi2752.github.io/Ml_map/

**Суть.** Всё, что с текстом: классификация, извлечение сущностей, генерация, перевод, диалог.

**Порядок изучения**
1. Токенизация (BPE, SentencePiece), классические эмбеддинги (word2vec, fastText)
2. RNN/LSTM — исторический контекст, знать концептуально
3. Transformer от и до: attention, positional encoding, encoder vs decoder
4. Encoder-модели: BERT, RoBERTa, ruBERT — классификация, NER, sentence embeddings
5. Seq2seq: T5, ruT5, BART — суммаризация, перефраз, детоксификация
6. Decoder-only LLM: авторегрессия, sampling, KV-cache
7. Файнтюнинг: full FT → LoRA/QLoRA/PEFT, instruction tuning
8. Alignment: RLHF, DPO — хотя бы понимать идею
9. RAG: чанкинг, dense retrieval, векторные БД (FAISS, Qdrant), реранкеры
10. Агенты и tool use, structured output, evaluation LLM (это самая свежая часть)

**Метрики.** Accuracy/F1, BLEU, ROUGE, chrF, BERTScore, perplexity, human eval. Для LLM отдельная боль — как вообще мерить.

**Русскоязычная специфика.** ruBERT, ruRoBERTa, ruT5, ruGPT, GigaChat, YandexGPT. Бенчмарки: Russian SuperGLUE, RuParaDetox, MERA.

**Порог входа.** Низкий на вход, высокий на глубину. Много конкуренции — сюда идут все.

**Где в Яндексе.** Поиск (переформулировки запросов), Алиса, Нейро, Переводчик, YandexGPT, поддержка.

> Твой проект по детоксификации ruT5 сидит именно здесь. Это правильная ветка, если ты в ней остаёшься.

### 2. Computer Vision

**Суть.** Изображения и видео: что на картинке, где именно, как её сгенерировать.

**Порядок изучения**
1. Свёртки, пулинг, рецептивное поле, аугментации (albumentations)
2. Классификация: ResNet → EfficientNet → ConvNeXt → ViT
3. Детекция: два семейства — двухстадийные (Faster R-CNN) и одностадийные (YOLO, RetinaNet), затем DETR
4. Сегментация: U-Net, Mask R-CNN, SAM
5. Metric learning: triplet loss, ArcFace — распознавание лиц, поиск похожих
6. OCR: детекция текста + распознавание
7. Генерация: GAN → VAE → диффузия (DDPM, latent diffusion, ControlNet) → flow matching
8. Видео: трекинг (ByteTrack), action recognition
9. 3D: NeRF, Gaussian Splatting (это уже нишевая глубина)

**Метрики.** Accuracy/top-5, mAP@IoU, IoU/Dice, FID/CLIP score для генерации.

**Порог входа.** Средний. Нужны GPU-часы — Colab бесплатный быстро упирается в потолок.

**Где в Яндексе.** Поиск по картинкам, Карты (распознавание домов, вывесок), Беспилотники, Маркет (модерация, поиск товара по фото), Шедеврум.

---

### 3. Speech / Audio

**Суть.** Речь в текст, текст в речь, всё звуковое.

**Порядок изучения**
1. DSP-минимум: сэмплирование, спектрограммы, мел-фильтры, MFCC
2. ASR: CTC-лосс → Conformer → Whisper → RNN-T (стриминг)
3. Language model rescoring, декодирование лучом
4. TTS: Tacotron → VITS → диффузионные вокодеры
5. Speaker recognition, диаризация (кто говорит когда)
6. Файнтюнинг под домен: LoRA на whisper, адаптация к акценту/лексике

**Метрики.** WER/CER для ASR, MOS для TTS.

**Порог входа.** Средний-высокий, зато конкуренция заметно ниже, чем в NLP/CV. Отличное соотношение "усилия / выделиться".

**Где в Яндексе.** Алиса, Телемост (субтитры), голосовой поиск, распознавание в Яндекс.Такси.

> Твоя идея с русским IT-сленгом и вкраплениями английских терминов — это ровно та ниша, где мало кто копал. Как pet-проект она выделяет сильнее, чем ещё один детокс-файнтюн.

---

### 4. RecSys (рекомендательные системы)

**Суть.** Что показать пользователю следующим. Один из самых денежных направлений в индустрии.

**Порядок изучения**
1. Постановка задачи: implicit vs explicit feedback, холодный старт
2. Коллаборативная фильтрация, матричные разложения (ALS, SVD++)
3. Двухстадийная архитектура: отбор кандидатов → ранжирование. Это ключевая идея всей области
4. Two-tower / DSSM модели, ANN-поиск (HNSW, FAISS)
5. Ранжирование бустингом на фичах — до сих пор рабочая лошадка
6. Sequential: SASRec, BERT4Rec, трансформеры над историей
7. Бандиты и exploration/exploitation
8. Онлайн-метрики и A/B, разрыв между офлайн- и онлайн-качеством

**Метрики.** Recall@k, NDCG, MAP, MRR + бизнес-метрики (CTR, время сессии, GMV).

**Порог входа.** Средний. Мало хороших курсов, много производственной специфики → меньше конкуренции среди студентов.

**Где в Яндексе.** Музыка, Маркет, Лавка, Дзен, реклама, главная страница. Это огромный кусок headcount.

---

### 5. Search / Ranking / Information Retrieval

**Суть.** Ядро Яндекса как компании. Найти релевантное среди миллиардов документов.

**Порядок изучения**
1. Инвертированный индекс, TF-IDF, BM25
2. Learning to Rank: pointwise / pairwise / listwise, LambdaMART
3. CatBoost для ранжирования (YetiRank — родная яндексовая тема)
4. Dense retrieval: би-энкодеры, кросс-энкодеры-реранкеры
5. Гибридный поиск (лексический + векторный)
6. Оценка качества: асессоры, pFound (яндексовая метрика), NDCG

**Порог входа.** Средний, но требует понимания high-load систем.

**Где в Яндексе.** Собственно Поиск. Плюс поиск внутри Маркета, Карт, Диска, Нейро.

---

### 6. Табличный ML в проде / антифрод / скоринг

**Суть.** Самое приземлённое и самое востребованное. Часто выигрывает у нейросетей на реальных данных.

**Порядок изучения**
1. Feature engineering: агрегаты по времени, target encoding, работа с высококардинальными категориями
2. Бустинги вглубь + интерпретация (SHAP)
3. Дисбаланс классов, стоимость ошибки, калибровка вероятностей
4. Дрифт данных, мониторинг качества модели в проде
5. Uplift-моделирование и причинно-следственный вывод — очень недооценённая тема, ценится высоко
6. A/B-тесты: мощность, MDE, подглядывание, CUPED

**Порог входа.** Низкий. Именно здесь стоит закрывать первый пет-проект (у тебя это Telco Churn).

**Где в Яндексе.** Антифрод, Пэй, скоринг в Такси/Доставке, аналитика продуктов.

---

### 7. Time Series / прогнозирование

**Суть.** Спрос, нагрузка, погода, цены, аномалии.

**Порядок изучения**
1. Разложение на тренд/сезонность, стационарность, ACF/PACF
2. Классика: ARIMA/SARIMA, экспоненциальное сглаживание, Prophet
3. Бустинг на лаговых фичах — самый частый рабочий вариант
4. Нейросети: N-BEATS, N-HiTS, Temporal Fusion Transformer, PatchTST
5. Правильная валидация (никакого случайного шаффла!), backtesting
6. Детекция аномалий

**Метрики.** MAE, RMSE, MAPE/sMAPE, WAPE, пинболл-лосс для квантилей.

**Порог входа.** Низкий-средний. Мало желающих → ниша.

**Где в Яндексе.** Прогноз погоды (Метеум), логистика Доставки/Лавки, планирование мощностей, ценообразование в Такси.

---

### 8. Reinforcement Learning

**Суть.** Обучение через взаимодействие со средой.

**Порядок изучения**
1. MDP, ценность состояния, уравнение Беллмана
2. Q-learning, DQN и его надстройки
3. Policy gradient → A2C/A3C → PPO
4. Многорукие бандиты и контекстные бандиты (практически самое применимое)
5. Offline RL
6. RLHF/DPO как мостик к LLM

**Порог входа.** Высокий. Много математики, тяжёлая отладка, мало продовых применений вне рекомендаций и робототехники.

**Где в Яндексе.** Беспилотники, роботы-доставщики, ранжирование/реклама (бандиты), алаймент моделей.

> Как основное направление для стажёра — рискованно. Как дополнительная глубина в связке с RecSys — сильно.

---

### 9. Мультимодальность

**Суть.** Текст + картинка + звук в одной модели. Самая быстрорастущая область.

**Порядок изучения**
1. CLIP: контрастное обучение, общее пространство эмбеддингов
2. Text-to-image: latent diffusion, ControlNet
3. VLM: BLIP-2, LLaVA, Qwen-VL — как картинку "приклеивают" к LLM
4. Видео-генерация, audio-language модели
5. Мультимодальный поиск

**Порог входа.** Высокий: нужно уже уметь и NLP, и CV. Это не первая ветка, а надстройка.

**Где в Яндексе.** Нейро, Шедеврум, поиск по картинкам, мультимодальная Алиса.

---

### 10. Graph ML

**Суть.** Данные как граф: связи, а не только объекты.

**Порядок изучения**
1. Эмбеддинги узлов: node2vec, DeepWalk
2. GCN, GraphSAGE, GAT
3. Задачи: классификация узлов, предсказание связей, детекция сообществ
4. Масштабирование на большие графы (сэмплирование соседей)

**Порог входа.** Средний, ниша узкая.

**Где в Яндексе.** Антифрод (графы транзакций), Карты (дорожный граф, маршрутизация), социальные связи, товарные графы.

## Слой 2. Инженерия (то, что делает из "делаю ноутбуки" ML-инженера)

Это не отдельное направление — это то, что накладывается сверху на любое из них. И это то, чем стажёр реально отличается от других стажёров.

- **Воспроизводимость:** структура проекта, конфиги (Hydra), DVC, MLflow / W&B
- **Продакшн:** FastAPI-сервинг, Docker, батч vs realtime инференс
- **Ускорение:** ONNX, TensorRT, квантизация, дистилляция, vLLM для LLM
- **Оркестрация:** Airflow, очереди, фичестор
- **Мониторинг:** дрифт данных и предсказаний, деградация качества, алерты
- **Данные:** SQL вглубь, основы Spark, работа с большими объёмами
- **ML System Design** — на собеседовании в Яндексе это отдельный блок. Нужно уметь спроектировать систему целиком: данные → фичи → модель → метрики → онлайн → мониторинг

У тебя тут уже есть база (Spring Boot, FastAPI, Docker, PostgreSQL, Ansible) — это преимущество, и его стоит явно показывать в резюме.

## Как выбрать

Три критерия:

1. **Что тебе интересно достаточно, чтобы копать вечерами полгода.** Без этого не доедешь.
2. **Где меньше конкуренции при том же уровне подготовки.** NLP и CV забиты. Speech, RecSys, Time Series, табличка+causal — заметно свободнее.
3. **Где в компании много вакансий.** В Яндексе это Поиск/ранжирование, RecSys, CV, Speech.

Пересечение всех трёх для тебя выглядит как **Speech (ASR)** или **RecSys** как основное, с NLP как вторым — потому что фундамент трансформеров у тебя уже нарабатывается.

**Что не надо делать:** пытаться закрыть 4 направления по верхам. Один законченный проект с внятным README, честными метриками и разбором ошибок весит больше, чем пять начатых ноутбуков.

## Что почитать/посмотреть по направлениям

- **Общее:** girafe-ai ML course (Нейчев), ШАД лекции, «Hands-On ML» Жерона, Deep Learning Book
- **NLP:** курс Hugging Face NLP, «Speech and Language Processing» (Jurafsky & Martin), блог Lil'Log
- **CV:** CS231n (Stanford), курс fast.ai
- **Speech:** документация NeMo, статьи по Whisper и Conformer
- **RecSys:** «Practical Recommender Systems», статьи по SASRec/BERT4Rec, доклады Яндекса и Ozon на конференциях
- **Search:** «Introduction to Information Retrieval» (Manning), документация CatBoost по ранжированию
- **MLOps:** «Designing Machine Learning Systems» (Chip Huyen) — must-read перед ML System Design
- **Практика:** Kaggle (не ради медалей, ради разборов чужих решений), ODS.ai
